# 第四阶段任务书：模组物体 + 设置开关 + 收尾

前置：第三阶段完成（每角色窗口能渲染角色、物理跑在碰撞体积上）。规格见 `docs/桌宠最终规格.zh-CN.md`。

## 1. 模组物体（规格 §5）

只有**对应模组启用时**才存在；未启用则不参与物理，也不参与遮挡：

| 物体 | 数据来源 | 物理行为 |
| --- | --- | --- |
| 桌面图标 | 现有桌面图标模组（`overlay:climb-platform` 通道已有雏形） | 只提供**顶面站立**，不做侧面阻挡 |
| 其他软件窗口 | 软件窗口模组（模组提供矩形列表） | 同上 |
| 攀爬落脚点 | 攀爬模组 | 同上 |

实现要求：

- 平台矩形由主进程汇总（物理像素），通过 `pet-window:platforms` 下发；无对应模组时下发空数组。
- 物理侧只做「顶面碰撞」：从上方落下时停住；从侧面接近不阻挡（可以走过去）。
- 平台只在主显示器范围内有效；跨屏不做。

## 2. 设置界面开关

- 在高级设置/桌面设置里暴露 `settings.overlay.perPetWindows`（每角色独立窗口），带说明文字。
- 切换后必须能立即生效（创建/销毁每角色窗口），且切换回 false 时回到旧的全屏 overlay 行为。
- 默认保持 false，直到手动验收通过后再考虑改成默认开启。

## 3. 收尾与验收

1. `npm run check`、`node electron/native-window.test.cjs`、`node electron/pet-layout.test.cjs` 全绿。
2. 逐条走 `docs/桌宠最终规格.zh-CN.md` 的 §1-§8，把每条标成「已实现 / 待修 / 暂不支持（说明原因）」。
3. 手动验收清单（必须实测并记录）：
   - 角色被任务栏挡住；任务栏区点击落到任务栏；
   - 点其他窗口盖住角色 / 点角色回最前且不抢键盘焦点；
   - 文字对话出现时临时抢焦点，点别的窗口立刻抢回；
   - 当前窗口被挡住时物理/动画继续；
   - 改大小后显示、碰撞、交互同步缩放，中心不动；
   - 重启后位置一致；关掉开关回到旧行为。
4. macOS：本机无法验证，先写清适配层设计（`NSWindow.setLevel/orderFront/setFrameOrigin`，Dock/菜单栏不参与遮挡），代码可留 TODO。
