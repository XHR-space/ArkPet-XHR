# 整机验收清单（逐条对照 docs/桌宠最终规格.zh-CN.md）

用法：每完成一个阶段就从头走一遍；每条必须给出「实测结果」，不允许只写"应该没问题"。
开关：`settings.overlay.perPetWindows`（false = 旧行为，true = 每角色独立窗口）。验收时两边都要跑。

## 准备

```powershell
npm run check
node electron/native-window.test.cjs
node electron/pet-layout.test.cjs
```

- [ ] 三条命令全绿
- [ ] 备份存在：`backups/pre-per-window-runtime-*` 与 tag `backup/pre-per-window-runtime`

## §1 固定显示

| # | 步骤 | 期望 | 实测 |
| --- | --- | --- | --- |
| 1.1 | 开关打开，看桌面 | 每只角色一个窗口，互不影响 | |
| 1.2 | 编辑器里量显示框中心到舞台中心的距离 | 一致（角色舞台中心 = 显示框中心） | |
| 1.3 | 试拖动显示框 | 不能拖动位置 | |
| 1.4 | 调整显示框尺寸并保存 | 桌面窗口尺寸随之变化，中心不动 | |
| 1.5 | 高级设置里找"角色显示缩放" | 不存在（不能单独调） | |
| 1.6 | 改 `pet.scale` / `overlay.scale` | 显示、碰撞、交互**同步**缩放 | |
| 1.7 | 编辑器里数值 | 始终是归一化尺寸（不随 scale 变） | |
