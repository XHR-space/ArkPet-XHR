# ArkPet 2.1.0 介绍片 · 视频思路与分镜脚本

> 用途：产品介绍 / 首发宣传 / 官网首屏视频 / 社交平台短版
> 目标成片：主片约 122 秒，另出 30 秒短版
> 规格：1920×1080 · 30fps · H.264 · 中文旁白 + 中文字幕

---

## 一、先定三件事

### 1. 片子要对谁说话

- 主力人群：喜欢角色、愿意折腾本地模型的人；有 GPU、愿意自己配 AI 的玩家。
- 次力人群：只想在桌面上有一只小动物陪着的普通用户。
- 因此片子必须做到：前 15 秒让普通人看懂"它是桌宠"，中段让进阶用户看到"它真的能训练角色和声音"。

### 2. 一句话定位

**ArkPet 是一个只在本机运行的桌面角色工作台：角色住在你的桌面上，人格、声音和记忆留在你的电脑里。**

全片所有镜头都围绕这句话展开，不介绍与它无关的功能。

### 3. 叙事主轴

采用"从看到角色，到看懂角色"的递进结构，而不是功能列表：

```
先让角色出现  →  说明它住在桌面  →  证明它不打扰你
→  展示它是可以自己做的  →  展示它能开口说话
→  展示它是可以被扩展的  →  收尾落到"数据留在本机"
```

每一步只回答观众心里的一个问题：

| 段落 | 观众此刻的疑问 | 片子给出的答案 |
|---|---|---|
| 开场 | 这是什么？ | 一只真的会走路的桌面角色 |
| 定位 | 和壁纸、聊天软件有什么不同？ | 它是一套完整的角色系统 |
| 桌面行为 | 会不会挡我？会不会卡？ | 鼠标穿透、物理行为、随时收回 |
| 角色制作 | 只能用自带的吗？ | 可以导入自己的 Spine 角色 |
| AI 与语音 | 它能说话吗？ | 档案决定性格，声线决定声音 |
| 模组 | 以后还能加东西吗？ | 模组独立更新，也能自己写 |
| 收尾 | 我的数据在哪？ | 全部留在本机，更新不动数据 |

## 二、视觉风格

直接沿用软件本身的配色与气质，保证"预告片和产品是同一个东西"。

| 元素 | 取值 | 用途 |
|---|---|---|
| 主蓝 | `#2f7df6` | 强调、进度、当前状态 |
| 主橙 | `#f59f38` | 次级强调、关系值、导航高亮条 |
| 主绿 | `#2b9a67` | 在线 / 正常 / 成功 |
| 侧栏深蓝 | `#18243a` | 信息卡片、字幕底板 |
| 纸色 | `#f4f2ec` | 亮底、界面底色 |
| 墨色 | `#172033` | 正文、标题 |

风格关键词：**安静的工程感 + 一点生活气**。不做炫技转场，不做全屏渐变，不用夸张的 3D 翻转。动效只做三件事：进来、对上重点、退场。

排版规则：

- 屏幕大字 ≥ 60px，正文 ≥ 28px，脚注 ≥ 22px。
- 中文字体优先 `Microsoft YaHei UI` / `PingFang SC` / `Noto Sans CJK SC`。
- 所有数字用等宽数字（tabular-nums），避免跳动。
- 屏幕文字必须是真实中文，禁止 `\uXXXX` 转义写法。

## 三、逐镜头分镜表

时间码为累计时间。每个镜头都写明"画面上发生了什么"和"观众听到什么"。

### 镜头 1 · 冷开场：角色走进画面（0:00 – 0:07，7 秒）

**画面**
干净的 Windows 桌面，壁纸轻微虚化，任务栏在底部。画面大部分是空的。
右侧边缘，一只 Spine 小角色走进来，走两步停住，抬头，挥手。

**动作细节**

- 0.0s 只有桌面和鼠标。
- 0.6s 角色从右边缘入画，脚下有很淡的接触阴影。
- 2.2s 停住，做一次待机呼吸。
- 3.0s 屏幕左侧浮出标题。

**屏幕文字**

```
ArkPet
本地角色工作台
```

**旁白**
> 你的桌面上，其实可以住着一个角色。

**动效与转场**
标题从左侧滑入并轻微上浮；角色挥手时给一次 4% 的镜头推进。结尾用一次"角色向前一步"作为切点，硬切到镜头 2。

---

### 镜头 2 · 定位：它到底是什么（0:07 – 0:16，9 秒）

**画面**
角色停在桌面中间。画面右侧依次浮出三张关键词卡：

```
本地优先
多只独立
可训练角色
```

三张卡随后向中间收拢，拼成一个应用窗口的轮廓，引出管理台。

**旁白**
> ArkPet 是一个只在本地运行的桌面角色工作台。
> 它不是壁纸，也不是聊天窗口，而是一套让角色真正住在桌面上的系统。

**动效与转场**
三张卡错峰入场（间隔 0.25s），用三种不同缓动避免节奏一致。收拢时用一次柔和的窗口化遮罩，转场到镜头 3。

---

### 镜头 3 · 主界面：六块功能一眼看清（0:16 – 0:28，12 秒）

**画面**
ArkPet 管理台窗口铺满画面。左侧导航依次被点亮：

```
首页总览
桌宠行为控制
桌宠唤醒
个性化 AI 训练
模组管理
数据与设置
```

点亮到"首页总览"时，镜头推进首页内容：角色卡、精力 / 主动性 / 关系三条计量条、今日桌面时长、当前心情、角色经历时间线。

**旁白**
> 打开工作台，六块功能一目了然。
> 首页总览把每一只桌宠的状态摊开给你看：精力、主动性、关系，还有今天陪了你多久。

**动效与转场**
导航高亮像扫描线一样从上到下走过；三条计量条从 0 长到真实数值；"经历"列表逐条淡入。

**屏幕文字**
`首页总览 · 一屏看到角色状态`

---

### 镜头 4 · 释放到桌面：它真的住在桌面上（0:28 – 0:42，14 秒）

**画面**
点右上角"从窗口释放"。管理台后退并淡出，角色落到真实桌面。
接着连续演示四个动作：

1. 按住拖动角色。
2. 松手，角色落下、弹跳、停稳。
3. 角色沿任务栏顶端行走。
4. 右键角色，弹出菜单。

**右键菜单内容**

```
文字对话
桌面休眠
收回并休眠
已绑定的模组入口（例如 查看饥饿值 / 攀爬平台模组 / 打开对话框）
```

**旁白**
> 点一下"从窗口释放"，角色就从窗口里走到你的桌面上。
> 拖动、落地、回弹、沿任务栏行走，都按真实的物理节奏来。
> 只有角色身体真正占用的区域会接收点击和拖动，其余位置鼠标穿透，不会挡住你正在用的软件。

**动效与转场**
每个交互点在画面上叠一个细环形高亮，点击处轻微放大到 1.06 倍。拖动与落地建议用 60fps 录制、后期放慢到 0.6 倍，物理会更清楚。

**屏幕字（依次出现在角落）**
`鼠标穿透` → `点击拖动` → `任务栏落点` → `右键菜单`

---

### 镜头 5 · 行为控制：一只桌宠一套物理参数（0:42 – 0:52，10 秒）

**画面**
打开"桌宠行为控制"，滑杆依次出现并被逐一拖动：

```
走路速度
地面摩擦
墙壁弹性
地面弹性
桌宠尺寸 60% – 160%
待机动作间隔与概率
重力锁定
多只相遇时的穿过概率
```

拖动"桌宠尺寸"时，右侧演示区的角色同步放大缩小。

**旁白**
> 走路快慢、摩擦力、弹性、显示大小，甚至多只桌宠相遇时是穿过还是撞开，都能在这里调。
> 调坏了也不怕，一键恢复默认值。

**动效与转场**
滑杆手柄拖动时给一条短的轨迹残影。最后一次拖动结束后，画面从"控制面板"叠化到"桌面实拍"，衔接镜头 6。

---

### 镜头 6 · 多只桌宠：各自独立（0:52 – 1:02，10 秒）

**画面**
桌面上同时出现三只不同角色。镜头分屏成三格，每格标出角色名。
随后演示：三只各自打开聊天窗口、首页左右切换角色时状态跟着切换。

**旁白**
> 每只桌宠都有独立的档案、声音、动作和聊天窗口。
> 多只同时上桌，互不干扰。

**屏幕文字**
`多角色独立 · 档案 / 声音 / 动作 / 对话`

**动效与转场**
分屏用三条纵向擦除同时展开，不逐个出现，保持"它们是在一起的"这种感觉。

---

### 镜头 7 · 角色制作：把自己的角色放进去（1:02 – 1:18，16 秒）

**画面**
进入"桌宠唤醒 → 新增桌宠"：

1. 依次导入 `.skel`、`.atlas`、纹理 PNG 三个文件。
2. 出现动作绑定清单，逐条点亮：

```
待机
走路
掉落
落地
被抓
睡眠
```

3. 画面上叠加三种高级调试框：显示画面、角色位置、碰撞区域，用三种描边色区分。

**旁白**
> 角色可以是 Spine 3.8 骨骼动画。
> 导入骨骼、图集和纹理三个文件，再把待机、走路、掉落、落地、被抓、睡眠绑定到对应动画上。
> 点击区域单独调，它贴着角色身体走，不会把角色的视觉位置带偏。

**动效与转场**
文件卡一张张落进导入区；动作清单逐条打勾；三个调试框最后同时出现，用一次短促的定格强调。

**屏幕文字**
`支持 Spine 3.8 · .skel + .atlas + PNG`

---

### 镜头 8 · AI 与语音：让它用自己的性格说话（1:18 – 1:38，20 秒）

这是全片最重的一段，分三个小节递进。

**8A 角色档案（1:18 – 1:25）**
画面：填写身份、性格、说话方式、世界观、喜好、缺点、关系边界。字段右侧实时生成角色 Skill 预览。
旁白：
> 角色档案决定它是谁：身份、性格、说话方式、世界观、关系边界，写一次就会稳定下来。
> 精力低、关系低的时候，它只会改变表达方式，不会变成另一个人。

**8B 文字对话（1:25 – 1:31）**
画面：在测试区输入一句话，角色回复逐字出现，回复风格与档案一致。
旁白：
> 可以直接在这里试对话。模型没启动的时候会退回内置角色回应，方便先检查设定。

**8C 声音链路（1:31 – 1:38）**
画面：切到"声音模块"，导入参考音频，选择 GPT-SoVITS，然后画面中央出现五步流水线：

```
麦克风录音 → ASR 语音识别 → LLM 按角色档案生成回复 → TTS 用绑定声线合成 → 播放
```

旁白：
> 接上本机的对话模型和 GPT-SoVITS，就能走完整条语音链路：录音、识别、生成、合成、播放。
> 模型需要自己导入，软件不会自动下载大模型。

**动效与转场**
五步链路像流水线一样依次点亮，当前步骤带一层呼吸光；语音播放时下方波形随声音起伏。8A/8B/8C 之间用同一次横向推移过渡，保持"这是一个连续流程"。

---

### 镜头 9 · 模组：功能可以长出来（1:38 – 1:50，12 秒）

**画面**
进入"模组管理"：

1. 官方模组库列出"对话框皮肤 / 攀爬平台模组 / 吃饭模组"，演示安装与更新。
2. 演示导入本地模组文件夹或压缩包。
3. 回到"桌宠唤醒 → 模组插件"把模组绑定到某一只桌宠。
4. 右键角色，菜单里出现该模组入口。

**旁白**
> 功能不用都塞进主程序。
> 官方模组独立更新，不用重装整个软件；也可以导入自己写的模组，绑定到某一只桌宠，从右键菜单直接进入。

**屏幕文字**
`模组与软件版本解耦`

**动效与转场**
模组卡片像抽屉一样滑入；绑定动作画一条从模组卡片到角色的短线，最后化成右键菜单里的一行。

---

### 镜头 10 · 数据与收尾：它一直留在你这（1:50 – 2:02，12 秒）

**画面**
进入"数据与设置"：

1. 数据目录路径逐字打出。
2. 导出备份 / 导入备份 / 打开角色存档依次高亮。
3. 主题四联屏快速切换：默认工房、紫苑、露蓝、青绿。
4. 关于更新：只替换程序文件，保留 `data/user-data`。

**收尾画面**
切回桌面。角色从远处走两步，停下，面向镜头。画面右下浮出标识与一句话：

```
ArkPet
让角色，真正住进桌面。
```

**旁白**
> 角色档案、声音样本、模型路径和对话设置，全部留在本机。
> 软件更新只替换程序文件，你的数据目录原封不动。
> 换电脑之前导出一次备份，就能全部带走。

**动效与转场**
主题切换用四次极快的同机位切换，制造"同一套界面、不同气质"的印象。最后 1.5 秒做一次轻微淡出到纸色底，收在标识上。

## 五、实现路径：HyperFrames 与 Remotion 怎么分工

两条工具链不要混着用同一件事，按"合成型镜头"和"剪辑型镜头"分工最稳。

| 内容 | 工具 | 理由 |
|---|---|---|
| 标题卡、关键词卡、导航扫描、五步语音链路、模组流水线、片尾标识 | HyperFrames | HTML + 时间轴直接可控，适合做精确的入场、强调、转场 |
| 真实界面录屏的裁剪、缩放、画中画、字幕烧录、多比例导出 | Remotion | 适合按数据驱动批量合成与多版本输出 |
| 桌面角色实拍（拖动、落地、行走、右键菜单） | 屏幕录制 | 必须录真实桌面，录制的是显示屏而不是应用窗口 |
| 旁白与配乐 | TTS 或真人录音 | 想突出本地语音，可直接用软件自己的 GPT-SoVITS 输出 |

### HyperFrames 负责的镜头

- 镜头 2 的三张关键词卡
- 镜头 3 的六项导航扫描与计量条动画
- 镜头 8C 的五步语音链路
- 镜头 9 的模组流水线与绑定动线
- 镜头 10 的片尾标识与标语
- 全片统一字幕条与场景转场

用 HyperFrames 时注意：

- 每个场景都要有入场动画，场景之间必须有转场，不允许硬切。
- 除最后一幕外不要写退场动画，退场交给转场完成。
- 所有时间轴同步构建，不要放在异步逻辑里。
- 不要用无限循环动画。

### Remotion 负责的镜头

- 把桌面实拍和 HyperFrames 输出的镜头按时间码拼成主时间轴。
- 给实拍片段加缩放、推近、环形高亮等包装。
- 烧录中文字幕，输出 16:9 主片与 9:16 短版。
- 用同一份数据批量生成不同时长的版本，避免手工剪多版。

### 录屏要点

- 分辨率 1920×1080，帧率 60fps，桌面缩放设为 100%。
- 关闭无关通知、聊天软件和多余的桌面图标。

## 六、30 秒短版怎么剪

短版只保留四个信息点，其余全部砍掉。

| 时间 | 内容 | 素材来源 |
|---|---|---|
| 0 – 5s | 角色走进桌面 + 标题 | 镜头 1 |
| 5 – 13s | 释放到桌面、拖动、落地、右键菜单 | 镜头 4 |
| 13 – 22s | 角色档案 → 文字回复 → 语音链路 | 镜头 8 的 8A/8B/8C 各取一段 |
| 22 – 30s | 模组入口一闪 + 数据留本机 + 片尾标语 | 镜头 9、10 |

> 你的桌面上，其实可以住着一个角色。
> ArkPet，本地运行的桌面角色工作台。角色可以自己做，性格可以自己写，声音可以自己训练。
> 档案、声音和数据，全部留在你的电脑里。
> 让角色，真正住进桌面。
