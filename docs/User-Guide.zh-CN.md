# ArkPet 2.1.0 使用说明

适用版本：ArkPet 2.1.0  
文档性质：独立用户手册，不在软件界面中显示

本手册面向第一次接触 ArkPet 的用户，也适合需要配置本地 AI、声音和模组的进阶用户。建议先完成基础流程，再按需进入 AI、语音和扩展章节。

## 如何使用本手册

这不是一份“按钮清单”，而是按实际使用顺序编写的说明书：

1. 先了解 ArkPet 是什么、和普通聊天软件有什么区别。
2. 学会启动、召唤、收回和操作桌宠。
3. 创建自己的角色，设置动作、碰撞和桌面行为。
4. 制作稳定的角色档案，让不同角色拥有不同性格和对话方式。
5. 接入本机 AI、语音识别与 GPT-SoVITS 语音合成。
6. 安装官方模组，或者制作自己的扩展模组。
7. 管理数据、备份、更新和排查常见问题。

## 1. ArkPet 的特色

ArkPet 是一个本地优先的桌面角色工作台。它把“桌宠显示”“角色人格”“语音”“模组”和“本地 AI 服务”拆成几层，再由每只桌宠分别绑定。

### 1.1 本地优先

- 角色档案、声音样本、模型路径、对话设置和桌宠状态都保存在本机。
- 除检查更新、下载官方资源或访问你配置的 API 外，软件不需要登录或云端账号。
- 关闭管理台时，桌宠仍可在桌面运行；真正退出要从“数据与设置 → 应用控制”。

### 1.2 多只桌宠相互独立

- 每只桌宠有自己的名称、动作、桌面位置、精力、主动性、关系和聊天窗口。
- 桌宠可以绑定不同的角色档案、声音模块和模组。
- 多只桌宠可同时出现在桌面，最后点击的聊天窗口获得键盘输入。

### 1.3 稳定且不干扰其他软件

- 视觉角色层保持鼠标穿透，只有角色实际区域接收点击和拖动。
- 右键菜单、自动文字气泡、文字聊天和语音提示均围绕角色可见位置定位。
- 完整文字聊天使用普通窗口，不置顶、不锁住其他软件。

### 1.4 从简单陪伴逐步扩展到本地 AI

- 不配置模型时，桌宠仍可显示、移动、互动、导入预录语音和播放动作。
- 绑定角色档案后，可以进行有性格的文字或语音对话。
- 绑定声音模块后，可以执行“语音识别 → AI 回复 → 语音合成”的完整链路。

### 1.5 模组与软件更新分离

- 官方模组放在仓库的模组库中，可单独下载和更新，不必重装整个软件。
- 用户可以导入符合规则的本地模组文件夹或压缩包。
- 模组通过受限的 `window.arkpet` 接口调用桌宠、对话、通知、存储和窗口能力。

## 2. 安装、启动与基本界面

### 2.1 首次启动

1. 运行 `ArkPet Setup 2.1.0.exe` 安装程序。
2. 安装完成后启动 ArkPet。
3. 首次打开会进入“首页总览”。
4. 软件数据位于安装目录的 `data/user-data`；自动更新只替换程序文件，保留这个目录。

便携版可以直接运行 `ArkPet Portable 2.1.0.exe`。便携版与安装版使用各自的程序位置保存数据。

### 2.2 主导航

左侧依次是六个主要页面：

- **首页总览**：查看当前桌宠的状态、关系、陪伴时间、活动记录和本地能力。
- **桌宠行为控制**：调整移动、待机、重力、显示大小和桌宠相遇规则。
- **桌宠唤醒**：管理角色列表、制作角色、动作、语音、模组插件和高级布局。
- **个性化 AI 训练**：管理角色档案、文字对话测试、声音模块和本地模型。
- **模组管理**：安装官方模组、导入本地模组、启停和编辑模组设置。
- **数据与设置**：主题、本地服务、数据目录、备份、自动更新和退出。

### 2.3 召唤与收回

打开“桌宠唤醒”，右上角按钮会跟随当前桌宠状态变化：

- 显示“从窗口释放”：把当前角色召唤到桌面。
- 显示“收回并休眠”：把当前角色从桌面收回。

召唤后，角色会出现在主显示器的桌面区域，并使用任务栏上沿作为主要落点。

### 2.4 关闭管理台与退出软件

- 关闭管理台窗口：软件隐藏到后台，桌宠继续运行。
- 双击桌宠：重新显示管理台。
- “数据与设置 → 应用控制 → 退出应用”：彻底结束管理台、桌宠和后台服务连接。

## 3. 桌面桌宠的基本使用

### 3.1 鼠标操作

- **单击并拖动**：移动桌宠；松手后保留惯性并落到桌面或任务栏上沿。
- **单击角色**：保持正常互动，不会抢走其他软件画面刷新。
- **双击角色**：显示 ArkPet 管理台。
- **右键角色**：打开当前角色的菜单。

右键菜单通常包含：

- 文字对话：打开这只角色自己的完整聊天窗口。
- 桌面休眠：角色留在桌面，但进入休眠表现。
- 收回并休眠：从桌面移除角色。
- 已绑定的模组入口：例如辅助窗口、对话框皮肤或攀爬模组。

### 3.2 首页总览

首页可以左右切换桌宠，也可以滑动角色区切换页面。主要信息包括：

- 当前心情、精力、主动性和关系阶段。
- 今日桌面陪伴时间和累计陪伴时间。
- 关系值；关系上限为 200。
- 模块提供的自定义属性，例如饥饿值。
- 本地对话模型、语音识别和语音合成状态。
- 当前角色的近期经历。

首页操作：

- **摸摸角色**：小幅增加关系和主动性。
- **聊一会儿**：打开该角色的完整文字聊天页。
- **让它休息**：让角色进入桌面休眠。

### 3.3 自动文字与自动语音

在“桌宠唤醒”的角色动作区中，可单独控制：

- **自动文字**：AI 在桌面上主动生成紧凑文字气泡。
- **自动语音**：控制 AI 语音和随机角色语音是否播放。

两个开关彼此独立，右键手动对话不受自动文字开关影响。

## 4. 桌面行为控制

### 4.1 移动物理

在“桌宠行为控制”中可以调整：

- **走路速度**：同时影响移动距离和走路动画速度。
- **地面摩擦力**：影响拖动后甩出时的惯性衰减，不改变正常行走。
- **墙壁弹性**：角色碰到屏幕左右边缘后的反弹程度。
- **地面弹性**：角色掉落到桌面后的反弹程度。

点击“恢复默认值”可以恢复这四项。

### 4.2 待机动作

- 开启后，每隔设定秒数进行一次概率判断。
- 触发概率越高，越容易出现待机动作。
- 待机动作开始后会完整播放，只有鼠标拖动才能打断。
- 可以彻底关闭待机动作，而不影响正常行走。

### 4.3 重力锁定

- **保持重力锁定**：角色主要在地面附近活动，适合普通桌宠。
- **解除重力锁定**：角色可以离开地面，在整个桌面区域自由移动。

### 4.4 显示大小

“桌宠尺寸”是全局显示比例，范围为 60% 到 160%。它只改变显示大小，不改变移动速度、摩擦力和角色各自的画面与碰撞数据。

### 4.5 多只桌宠相遇

“相互穿过概率”控制多只桌宠重叠时的行为：

- 数值高：更容易上下分层穿过。
- 数值低：更容易发生碰撞后反向分开。

### 4.6 快捷模组

“桌宠行为控制”右侧可以添加全局快捷模组。对话框皮肤等模组可以在这里调整大小、背景或直接打开。

## 5. 角色制作与动作

### 5.1 创建 Spine 角色

在“桌宠唤醒”中点击“新增桌宠”，依次导入：

1. `.skel` 骨骼文件。
2. `.atlas` 图集文件。
3. 图集声明的纹理页 PNG。

ArkPet 只接受 Spine 3.8 骨骼。导入后会自动检查动画名称，纹理图片也会按图集要求自动处理。

### 5.2 动作预设

角色制作完成后，可以为以下动作分别绑定 Spine 动画：

- 待机
- 走路
- 掉落
- 落地
- 被抓
- 休眠

每项都可以选择“通用动作”或该角色的具体动画，并点击“播放”预览。

### 5.3 角色名与角色档案名

同类项目内名称不能重复：

- 桌宠名称只能在同一只桌宠列表内唯一。
- 角色档案名称只能在角色档案库内唯一。
- 声音模块名称只能在声音模块库内唯一。
- 不同类别可以重名，例如桌宠和声音模块可以同名。

输入重复名称时会显示“名字已存在”。保存时如果仍未修改，软件会自动追加数字编号。

### 5.4 角色预录语音

“角色语音”用于桌面随机播放固定语音：

- 当前只支持 WAV 文件。
- 可以设置播放间隔和触发概率。
- 触发时仍可能因为概率判断而不播放。
- 每段语音可以单独试听或删除。

预录语音和 AI 动态语音是两套机制：预录语音不需要 AI 或语音模型。

### 5.5 模组插件绑定

每只桌宠都有三个绑定位置：

- **语音插件**：选择一只声音模块，决定这只角色怎样发声。
- **角色档案**：选择稳定的性格、身份和说话方式，决定这只角色的回复身份。
- **模组**：添加外部模组入口，绑定后会出现在右键菜单中。

角色没有绑定角色档案时，文字对话不可用。角色没有绑定声音模块时，只能显示文字，不能动态合成语音。

## 6. 角色高级设置

打开“桌宠唤醒 → 高级设置”后，当前角色会暂时冻结，便于精确调整。

### 6.1 三种调试模式

- **角色位置调试**：调整角色在显示画面中的位置。
- **碰撞区域调试**：调整桌面实际点击和拖动区域。
- **显示画面调试**：调整给动作预留的画面范围。

### 6.2 推荐调整顺序

1. 先调整“显示画面”，给动作留出空间。
2. 再调整“角色位置”，让角色在画面中的位置正确。
3. 最后调整“碰撞区域”，让点击区域贴住角色身体。
4. 调整完成后点击“保存高级设置”。

调整碰撞框不会移动角色视觉位置；调整角色位置时，碰撞框会一起移动。这样不需要在两套数值之间反复来回校准。

### 6.3 拖动与取消

- 拖动使用实时草稿，每帧最多更新一次。
- 按 `Esc` 可以取消本次拖动并恢复拖动前的值。
- 鼠标在窗口外松开、窗口失焦或指针取消时，拖动会安全结束。
- 只有点击保存才把改动写回角色数据。

### 6.4 未保存改动

- 离开高级设置、切换角色或关闭软件时，如果存在未保存改动，会提示处理。
- 临时草稿在当前会话内保留，从其他页面返回后可以继续编辑。
- 切换角色可以选择保存、放弃或取消。

## 7. 个性化 AI：角色档案

打开“个性化 AI 训练 → 角色档案”。

### 7.1 角色档案和运行时 Prompt

ArkPet 把角色 AI 分为两层：

- **角色 Skill / 角色档案**：稳定身份、性格、说话方式、世界观、喜好、弱点和关系边界。
- **运行时 Prompt**：根据当前精力、主动性和关系自动生成，不覆盖角色档案。

这比把所有内容都写在一个长提示词里更稳定，也更容易维护。

### 7.2 建议填写的档案内容

- 角色名和身份。
- 性格：稳定但具体的性格描述。
- 说话方式：称呼、语气、句长、口癖和禁忌。
- 世界观与经历：角色来自哪里、经历过什么。
- 核心在意的事情。
- 抗拒与弱点。
- 与用户的关系，例如搭档、下属、朋友或保持距离的合作者。

角色档案是角色的“底线”。精力低、关系低或主动性低时，只改变表达方式，不会让角色变成另一个人。

### 7.3 长期资料与记忆

角色档案的数据结构支持资料文档和长期记忆：

- 资料适合放故事、设定、台词样本和世界观。
- 记忆适合放需要长期保持的偏好、约定和关键经历。
- 资料和记忆应精简明确，避免把所有聊天记录都塞进去。

### 7.4 文字对话测试

在“文字对话”中可以临时选择角色档案进行测试。模型不可用时会先用内置角色回应，方便检查页面、记忆和角色边界。

## 8. 本地 AI 与模型管理

打开“个性化 AI 训练 → 模型管理”。

### 8.1 三种模型角色

- **语音合成 TTS**：把文字变成语音。
- **语音识别 ASR**：把用户录音变成文字。
- **对话模型 LLM**：根据角色档案生成文字回复。

每种能力都可以选择本地模式或 API 模式。对话模型的 API 模式可以直接填写 API 地址、模型名称和 API Key。

### 8.2 本地模型导入

- 软件不会自动下载大型语言模型。
- 对话模型支持选择单个 `.safetensors` 或完整模型文件夹。
- 语音识别支持选择本地模型文件夹。
- 导入后软件检查必需文件，并把可用的模型登记到模型库。
- 可用模型可以点击“设为当前模型”。

### 8.3 对话模型适配

首版重点适配 Qwen 和 DeepSeek；GGUF、Llama、Mistral 和 Gemma 保留了相同的接入位置，后续可通过适配包扩展。

### 8.4 服务连接测试

在“数据与设置 → 本地 AI”可以填写：

- 对话模型服务地址和模型名。
- 语音识别服务地址和模型名。
- 语音合成服务地址和声线 ID。

填写后点击“测试连接”，确认本机服务已经启动。

## 9. 声音模块与语音合成

打开“个性化 AI 训练 → 声音模块”。

### 9.1 语音引擎与声线权重

ArkPet 使用本机 GPT-SoVITS 作为核心语音合成引擎。

需要准备：

1. GPT-SoVITS 官方整合包，约 6.4 GB。
2. GPT 权重 `.ckpt`。
3. SoVITS 权重 `.pth`。

操作顺序：

1. 点击“从官方下载语音引擎”。
2. 解压后点击“选择本地引擎文件夹”。
3. 引擎位置变化后重启软件。
4. 从官方下载 `.ckpt` 和 `.pth`，或者分别点击“选择本地文件”导入。
5. 两项权重都导入后，自定义声线会启用。

### 9.2 导入声音样本

声音样本支持：

- WAV
- MP3
- M4A
- FLAC
- OGG
- WEBM

至少准备一段干净、无混响、单一说话人的参考音频。填写“参考音频原话”会让声线更稳定。

### 9.3 保存声音模块

1. 新建声音模块。
2. 填写模块名称和参考音频原话。
3. 添加声音样本。
4. 选择默认 AI 模块。
5. 点击“保存声音模块”。

保存后，声音模块才会进入模块库，并可绑定到桌宠。

### 9.4 声音模块与角色的关系

- 声音模块负责“怎么发声”。
- 角色档案负责“说什么、用什么性格说”。
- 桌宠的语音插件负责把两者绑定到这只角色。

### 9.5 语音训练

语音训练需要：

- 至少 3 段音频，或总时长超过 1 分钟。
- 每段音频对应的文字转写。
- 可用的 CUDA 12.8 训练环境。

流程：

1. 点击“添加训练音频”。
2. 使用 Whisper 转写，或手动填写原话。
3. 检查总时长和音频数量。
4. 点击“准备训练数据”。
5. 环境就绪后再进入后续训练流程。

Whisper 转写结果可以手动修改，建议逐段校对。

### 9.6 语音合成格式

- 软件生成的语音输出为 WAV。
- 导入的声线样本和训练素材支持 MP3。
- 角色随机播放的预录语音目前只支持 WAV。

### 9.7 语音对话链路

完整链路为：

```text
麦克风录音
→ ASR 语音识别
→ LLM 根据角色档案生成回复
→ TTS 使用绑定声线合成
→ 播放语音
```

语音对话需要：

- 已绑定角色档案。
- 已绑定声音模块。
- 可用的语音识别服务或本地模型。
- 可用的语音合成服务和权重。

## 10. 模组管理

打开“模组管理”。

### 10.1 安装官方模组

1. 点击“打开官方模组库”。
2. 软件读取仓库中的模组清单。
3. 点击“安装”或“更新”。
4. 安装后的模组会出现在本地模组库中。
5. 官方模组更新不需要重新发布整个软件。

### 10.2 导入本地模组

支持两种方式：

- 导入包含 `module.json` 或 `manifest.json` 的文件夹。
- 导入符合规则的压缩包。

导入后还需要在“桌宠唤醒 → 模组插件”中绑定给具体桌宠，右键菜单才会显示入口。

### 10.3 模组作用范围

- **全局作用模组**：可用于整个软件或添加到行为控制快捷区。
- **角色作用模组**：绑定给具体桌宠。

### 10.4 模组分类

- 对话框皮肤
- 辅助窗口
- 交互模组
- 外部扩展

### 10.5 模组开发基础

一个模组就是一个文件夹：

```text
my-module/
  module.json
  index.html
  其他资源
```

最少需要：

- `module.json`
- 入口页面，默认 `index.html`

常用字段：

- `id`：模组唯一标识。
- `name`：显示名称。
- `version`：模组版本。
- `apiVersion`：当前为 1。
- `type`：`interaction` 或 `dialog-box`。
- `scope`：`global` 或 `pet`。
- `category`：模组分类。
- `entry`：入口页面。
- `contextMenuLabel`：右键菜单文字。
- `width`、`height`：窗口初始尺寸。
- `quickControl`：是否出现在行为控制快捷区。

### 10.6 模组可用接口

模组入口页面通过 `window.arkpet` 调用软件能力：

```text
arkpet.module.info()
arkpet.pets.list()
arkpet.pets.active()
arkpet.pets.onChanged(fn)
arkpet.pet.command({ type })
arkpet.chat.ask(text, petId?)
arkpet.voice.speak(text)
arkpet.storage.get / set / remove / keys
arkpet.activity.log(text)
arkpet.app.notify(title, body)
arkpet.app.openExternal(url)
arkpet.ui.setSize(w, h)
arkpet.ui.setTitle(text)
arkpet.ui.close()
```

模组不能直接访问 Node 或文件系统，只能使用 ArkPet 提供的安全接口。

## 11. 数据、设置与更新

### 11.1 皮肤主题

“数据与设置 → 皮肤主题”提供：

- 默认工房
- 紫苑
- 霜蓝
- 青绿

主题只影响管理台界面，不改变角色素材和桌面桌宠。

### 11.2 数据目录

- 软件数据目录：整个 ArkPet 的数据根目录。
- 用户数据子目录：软件目录下的 `data/user-data`。
- 用户数据在自动更新时保留。

主要文件：

- `desk-pet-state.json`：主状态文件。
- `pet-store/`：每只角色的独立存档。
- `assets/`：角色图片、声音样本和语音文件。

### 11.3 备份与恢复

- **导出备份**：导出当前用户数据。
- **导入备份**：替换当前状态，导入前会确认。
- **保存独立角色文件**：把每只角色同步到 `pet-store`。
- **打开角色存档**：查看角色独立文件目录。

更换电脑、重装软件或修改重要角色之前，建议先导出备份。

### 11.4 自动更新

- 软件会后台检查新版本。
- 新版本下载完成后，可以立即更新并退出，或者在正常退出时替换程序文件。
- 更新只替换程序文件，保留 `data/user-data`。
- 开发运行模式不会自动安装更新。

### 11.5 手动检查与退出

- “检查更新”用于立即检查版本。
- “立即更新并退出”只在更新已准备好时出现。
- “退出应用”才会真正关闭后台和桌宠。

## 12. 常见使用流程

### 12.1 最小可用流程：只让桌宠上桌

1. 启动 ArkPet。
2. 打开“桌宠唤醒”。
3. 选择角色。
4. 点击“从窗口释放”。
5. 在“桌宠行为控制”中调整速度、大小和待机动作。

### 12.2 让角色可以文字对话

1. 在“个性化 AI 训练 → 角色档案”中填写角色档案。
2. 保存并生成角色 Skill。
3. 在“模型管理”中配置本地对话模型或 API。
4. 在“桌宠唤醒 → 模组插件 → 角色档案”中绑定这只角色。
5. 右键桌宠，选择“文字对话”。

### 12.3 让角色可以完整语音对话

1. 完成文字对话配置。
2. 安装 GPT-SoVITS 引擎。
3. 导入 `.ckpt` 和 `.pth` 权重。
4. 创建并保存声音模块。
5. 在“模组插件 → 语音插件”中绑定声音模块。
6. 配置语音识别服务或本地 ASR 模型。
7. 在声音模块中使用“开始对话”，完成录音、识别、回复和发声。

### 12.4 制作一只自己的角色

1. 准备 Spine 3.8 的 `.skel`、`.atlas` 和纹理 PNG。
2. 在“桌宠唤醒”中新增角色并导入素材。
3. 绑定待机、走路、掉落、落地、被抓和休眠动作。
4. 调整显示画面、角色位置和碰撞框。
5. 保存角色。
6. 绑定角色档案和声音模块。
7. 从窗口释放到桌面测试。

### 12.5 开发一个自己的模组

1. 建立模组文件夹并写 `module.json`。
2. 创建 `index.html`。
3. 通过 `window.arkpet` 调用桌宠、对话或存储接口。
4. 在“模组管理”导入文件夹测试。
5. 在“模组管理”中启用并编辑设置。
6. 在“桌宠唤醒 → 模组插件”中绑定到角色。
7. 右键角色测试模组入口。

## 13. 常见问题

### 桌宠没有出现在桌面

- 检查是否点击了“从窗口释放”。
- 检查“桌宠唤醒”右上角是否显示“从窗口释放”。
- 检查 Windows 是否把 ArkPet 窗口置于手动最小化或隐藏状态。

### 右键没有文字对话

角色没有绑定角色档案时不会开放文字对话。到“桌宠唤醒 → 模组插件”绑定一个角色档案。

### 有声音模块但不发声

依次检查：

1. GPT-SoVITS 引擎是否已安装。
2. `.ckpt` 和 `.pth` 是否已导入。
3. 声音模块是否已保存。
4. 角色是否绑定了该声音模块。
5. 语音服务是否测试通过。

### 导入 MP3 后能不能用

可以。声音样本和训练素材支持 MP3。软件内部会通过 FFmpeg 解码，并使用 WAV 数据进行模型处理。

### 为什么生成的语音是 WAV

当前 GPT-SoVITS 合成输出固定使用 WAV，播放器直接播放 WAV。上游引擎虽然支持其他格式，但 ArkPet 当前不会把合成结果显示为 MP3。

### 为什么角色随机语音只能导入 WAV

角色预录语音是直接播放的固定音频，不是训练样本。当前选择器只开放 WAV，因此 MP3 需要先转成 WAV 再导入。

### 高级设置里碰撞框和角色对不上

- 先确认显示画面框足够覆盖动作。
- 再调角色位置，让角色落到正确位置。
- 最后调碰撞框，不要反过来用碰撞框移动角色。
- 调完必须点击“保存高级设置”。
- 调整静止姿态后，换动作可能产生新的可见范围，这是动作本身的变化，不属于同步错误。

### 模组安装了但不显示

- 检查模组是否启用。
- 检查作用范围是全局还是角色。
- 如果是角色模组，需要绑定到具体桌宠。
- 右键菜单只显示已绑定且启用的模组。

### 软件更新后数据会丢失吗

正常更新不会。用户数据保存在 `data/user-data`，更新只替换软件程序文件。重大操作前仍然建议导出备份。

## 14. 功能分阶段速查表

| 阶段 | 你会得到什么 | 主要入口 |
|---|---|---|
| 基础 | 桌宠显示、移动、待机、互动 | 首页总览、桌宠行为控制 |

## 15. 一句话总结每个特色

- **本地优先**：人格、声音、模型设置和数据主要留在本机。
- **角色分层**：角色档案管稳定人格，运行时 Prompt 管精力、主动性和关系。
- **多角色独立**：每只桌宠可拥有独立档案、声音、动作和聊天窗口。
- **桌面稳定**：点击、拖动和右键不穿透；聊天使用普通窗口；其他软件不被锁死。
- **声线可训练**：既能直接使用参考音频，也能为长期稳定声线准备训练数据。
- **模组可扩展**：官方模组独立更新，用户也可以制作和导入自己的模组。
- **更新保数据**：软件更新替换程序文件，用户数据目录继续保留。
